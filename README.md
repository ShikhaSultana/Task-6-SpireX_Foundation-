# Task-6-SpireX_Foundation-
Task 6: Digital Clock:
<br>
A real-time digital clock built with HTML, CSS, & JavaScript that dynamically displays the current time and updates every second with a clean, responsive interface.
<br>
I developed a responsive digital clock using HTML, CSS, and JavaScript. I used JavaScript's Date object to get the current system time and setInterval() to update the clock every second. I also implemented 12-hour and 24-hour formats, AM/PM display, current date, responsive styling, and CSS animations.
